# Week 1 reflection

Answer each question in 1–3 sentences, in your own words.

1. What is the difference between building a UI imperatively (plain DOM code) and declaratively (React)?

Answer: React JSX simplifies the process of writing and managing UI components.

2. Why must a component name start with a capital letter?

Answer: React use the capitalization of the tag name to determines whether it should treat the element as
a built-in tag or custom component.

3. What does a fragment <>...</> do, and why not just use a <div>?

Answer: Using a fragment allows developers to avoid unnecessary markups and nesting.

4. Name one benefit of splitting the UI into small components.

Answer: smaller components are generally easier to maintain, refactor and update.
